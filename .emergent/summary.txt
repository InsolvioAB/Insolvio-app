<product_requirements>
The goal is to build Konkurskoll, an offline-first mobile application for Swedish legal professionals, particularly in bankruptcy administration.

**Core Features:**
1.  **Legal Text Viewer:** Display the full text of key Swedish laws, organized by chapters and sections. The content must be searchable and easy to navigate.
2.  **Offline Access:** All legal texts must be bundled with the app for full functionality without an internet connection.
3.  **Search:** A robust search function that allows users to find content by keywords (e.g., gäldenär) and specific section numbers (e.g., 5 §).
4.  **Bookmarking:** Users must be able to bookmark specific law sections for quick access.
5.  **Notes:** Users should be able to add personal notes to law sections (this was a feature from the initial document, implemented via context).

**Content Requirements:**
The app must contain the complete and unabridged versions of the following Swedish laws:
*   Konkurslag (1987:672)
*   Lag om handelsbolag och enkla bolag (1980:1102) (which includes kommanditbolag)
*   Lag om anställningsskydd (LAS) (1982:80)
*   Utsökningsbalken
*   Aktiebolagslag (ABL) (2005:551)

The user interface and all content must be in Swedish. The initial MVP is working, but its legal text data is incomplete. The current task is to populate the app with the full legal texts provided by the user in DOCX format.
</product_requirements>
